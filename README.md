# 🌊 Sabores da Costa | SaaS B2B para Gestão de Restaurantes

> Uma solução web completa e interativa projetada para otimizar o atendimento de salão, o fluxo de pedidos para a cozinha e a gestão de cardápios em tempo real para estabelecimentos gastronómicos.

## 🚀 Sobre o Projeto
O **Sabores da Costa** simula um software como serviço (SaaS) voltado para o setor de restaurante. O sistema divide-se em duas vertentes principais:
1. **Site Público (Cardápio Digital):** Onde o cliente simula a escolha da mesa, navega pelas categorias de pratos e adiciona itens ao carrinho para submeter o pedido instantaneamente.
2. **Painel Administrativo (SaaS Dashboard):** Um painel restrito para gestores e staff acompanharem mesas ativas em tempo real, gerirem o estado dos pedidos, efetuarem a impressão de comandas de cozinha e analisarem o faturamento diário.

---

## 🛠️ Funcionalidades Principais

* **Cardápio Dinâmico e Categorizado:** Organização automática por Entradas, Pratos Principais, Sobremesas e Bebidas.
* **Gestão de Mesas Interativa (Drag and Drop):** Permite reorganizar a disposição das mesas e monitorizar visualmente quais estão livres ou ocupadas.
* **Fluxo de Pedidos em Tempo Real:** Envio direto do cardápio para o painel de controlo do restaurante.
* **Comandas para Cozinha (`@media print`):** Formatação limpa e otimizada para impressão rápida de pedidos na cozinha.
* **Sandbox com `localStorage`:** Permite adicionar novos pratos (com upload de imagens reais do dispositivo via `FileReader`), criar/remover mesas e simular vendas sem necessidade de backend tradicional.

---

## 💻 Tecnologias Utilizadas

* **HTML5 Semantic:** Estrutura clara e acessível das páginas.
* **CSS3 Avançado:** Variáveis CSS (`:root`), design responsivo para dispositivos móveis e desktop, e identidade visual moderna com paleta temática.
* **JavaScript (Vanilla):** Manipulação avançada do DOM, persistência de dados local e lógica de negócio totalmente integrada.
* **Font Awesome:** Ícones intuitivos para melhorar a experiência visual da interface.
